Checked Exception을 컴파일 단계에서 try-catch로 감싸 runtime exception로 처리해주는 코드를 만들어준다.

```java
public class Example { 
	public static String readFile(String path) throws IOException { 
		return Files.readString(Path.of(path)); 
		} 
	}
```

위와 같은 코드가 아래처럼 간단해진다.

```java
import lombok.SneakyThrows; public class Example { 

	@SneakyThrows 
	public static String readFile(String path) { 
		return Files.readString(Path.of(path)); 
	} 
}
```

실제 런타임에서 오류가 발생하면 시그니처에 정의된 예외를 던지게 된다.

`@FunctionalInterface`와 함께 사용해서 람다로 정의된 메서드에서 발생하는 예외를 간단하게 처리할 때 유용하다.

다만 코드만 봤을 때는 메서드가 어떤 예외를 던지는 지 알기 어렵고, 발생한 예외를 처리할 방법이 없으므로 간단한 코드, 테스트 같이 예외 발생 상황이 명확한 경우에 사용하는 게 좋을 것 같다.
