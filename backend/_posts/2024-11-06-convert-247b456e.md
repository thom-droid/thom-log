# 문제 

`List<Enum<T>`을 문자열로, 문자열을 리스트로 리턴하는 컨버터를 만들어 상속이 가능한 타입 파라미터를 가진 컨버터를 만들었다.

```java
package com.millktea.core.config.jpa.converter;  
  
import jakarta.persistence.AttributeConverter;  
import jakarta.persistence.Converter;  
import lombok.RequiredArgsConstructor;  
  
import java.util.List;  
import java.util.stream.Collectors;  
import java.util.stream.Stream;  
  
/**  
 * List<Enum<E>> -> String  
 * 해당 클래스를 상속하여 원하는 enum 타입을 생성자 파라미터로 넣으면 해당 타입 enum 또는 문자열로 변환  
 */  
@Converter  
@RequiredArgsConstructor  
public class ListEnumStringConverter<E extends Enum<E>> implements AttributeConverter<List<E>, String> {  
  
    private final Class<E> enumType;  
  
    @Override  
    public String convertToDatabaseColumn(List<E> enums) {  
        return enums != null ? enums.stream()  
                        .map(Enum::name)  
                        .collect(Collectors.joining(",")) : null;  
    }  
  
    @Override  
    public List<E> convertToEntityAttribute(String s) {  
        return s != null ? Stream.of(s.split(","))  
                        .map(name -> Enum.valueOf(enumType, name))  
                        .collect(Collectors.toList()) : null;  
    }  
}
```

아래처럼 다른 enum도 쉽게 사용할 수 있게 하려 했다.

```java

@Converter  
public class ListPrivilegeConverter extends ListEnumPrivilegeConverter<List<User.Privilege> { 

	public ListPrivilegeConverter(){
		super(User.Privilege.class);
	}
  
    
}
```

```java

@NotNull  
@Column(nullable = false)  
@Convert(converter = ListPrivilegeConverter.class)
@Enumerated(STRING)
@Builder.Default  
private List<Privilege> privileges = new ArrayList<>();

```

그런데 테스트하니 오류가 났다. ddl에서 문제가 있어보였다.

```java
Hibernate: 
    create table users (
        business_id bigint,
        created_at timestamp(6),
        id bigint generated by default as identity,
        modified_at timestamp(6),
        name varchar(20) not null,

```

privileges 컬럼이 enum array 타입으로 선언되었고, 실제 데이터 삽입 시 컨버터에 의해 문자열로 변환된 값이 들어가다보니 `DataIntegrationException`이 던져졌다.

# 해결 방법

1. `@Enumerated`제거
	- 컨버터의 결과값에 의해 자동으로 설정되므로 필요없다. 해당 어노테이션은 enum 타입으로 설정하도록 하므로 지워야 한다.
2. `ListEnumPrivilegeConverter` 확장 제거 및 직접 구현체 선언
	- 자식 클래스인 `ListPrivilegeConverter`가 생성자를 통해 부모 클래스를 호출하는데 여기에서 스프링이 의존성 주입을 해줄 수가 없다고 한다. 좀 더 정확히는  `@Convert`을 사용할 때는 생성자를 통한 의존성 주입을 지원하지 않으므로 직접 구현해서 사용해야 한다고 한다. (by GPT)
	- Adding `@Component` to `ListPrivilegeConverter` would indeed register it as a Spring bean, but this approach won't resolve the problem in your case. The issue is that Spring cannot automatically inject the `Class<E>` parameter into the constructor of the `ListPrivilegeConverter`. The `@Convert` annotation does not support constructor injection by Spring, which is why the bean injection isn't working for your use case.


```java
package com.millktea.core.config.jpa.converter;  
  
import com.millktea.core.domain.user.entity.User;  
import jakarta.persistence.AttributeConverter;  
import jakarta.persistence.Converter;  
import org.springframework.stereotype.Component;  
  
import java.util.List;  
import java.util.stream.Collectors;  
import java.util.stream.Stream;  
  
@Converter  
public class ListPrivilegeConverter implements AttributeConverter<List<User.Privilege>, String> {  
  
    @Override  
    public String convertToDatabaseColumn(List<User.Privilege> enums) {  
        return enums != null ? enums.stream()  
                        .map(Enum::name)  
                        .collect(Collectors.joining(",")) : null;  
    }  
  
    @Override  
    public List<User.Privilege> convertToEntityAttribute(String s) {  
        return s != null ? Stream.of(s.split(","))  
                        .map(User.Privilege::valueOf)  
                        .collect(Collectors.toList()) : null;  
    }  
}
```

```java

@Convert(converter = ListPrivilegeConverter.class)  
@Builder.Default

```
