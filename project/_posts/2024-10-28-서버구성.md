# 서버구성
- 간단하게 진행한다.
- RDBMS : MySQL 8.0
- ORM : JPA (Hibernate)
- Framework : Spring Boot
- Build Tool : Gradle
- Cache : Redis

# 모듈
- core : DB 설정, JPA 및 프로젝트 전반의 설정을 담당하는 모듈
- api : 요청을 수행하여 응답을 반환하는 모듈

# 도메인
- Business : 회사 정보. 회사로 먼저 가입한다.
- User : 회사에 속한 유저 정보. 회사에 속한 유저로 로그인한다. Business와 User는 1:N 관계이다.
- Partner : 회사에 속한 파트너 정보. Business와 Partner는 1:N 관계이다.
- TaxInvoice : 세금계산서 정보. Business와 TaxInvoice는 1:N 관계이다.
- CashReceipt : 현금영수증 정보. Business와 CashReceipt는 1:N 관계이다.
- DepositWithdraw : 입출금 정보. Business와 DepositWithdraw는 1:N 관계이다.
- Voucher : 전표 정보. Business와 Voucher는 1:N 관계이다. 위 세 가지 도메인은 모두 전표로 변환될 수 있다. 
- Item : 각 도메인의 상세 정보. 각 도메인과 1:N 관계이다.
- JournalEntry : 분개 정보. 각 도메인과 1:N 관계이다.
