#### 유저 생성 및 권한 부여
redis 에는 다른 rdb와 같이 특정 유저에게 특정 스키마 권한을 줄 수 없다.
```
ACL SETUSER db1_user on >your_secure_password ~db1:* +@all
```
- db1_user 라는 사용자 생성 후 특정 클러스터 (db1)에 모든 권한(+@all) 부여
- 수정할 때는 똑같이 사용자 정보를 입력하고 권한 값만 다르게 주면 된다.

```
ACL SETUSER db1_user on >your_secure_password ~* +@all
```
- db1_user 의 권한을 모든 클러스터로 변경


#### 유저 접속

```
AUTH [USERNAME] [PASSWORD]
```
